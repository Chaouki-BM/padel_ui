# UI/UX Brief — Padel platform, Tunisia

Product: platform connecting players, clubs, coaches, organizers and sponsors. Features: court booking, open matches,
rating/ranking, events (Americano, Mexicano, tournaments), coaching, token wallet, sponsors and ads.
Users: players (mobile first), club managers (dashboard), coaches, admin, sponsors.
Language: French UI (Arabic RTL later). Currency TND. Phone-first onboarding (OTP). Cities: Tunis, Sousse, Monastir.
Payments: bank card + pay on site.

Style: sporty, premium, clean, light/dark. Suggested palette: deep navy or dark green + electric lime accent + white;
red = unavailable, green = available. Rounded cards, touch targets >= 44px, bold readable typography.
NOTE: the real visual tokens will come from the Visily design that will be added in docs/design/ later.

Key components: availability calendar/SlotGrid (courts x times; available/booked/blocked/selected; discount badge),
level badges (P25, P50, P100, P250, P500, P1000 + rating + ranking), Open Match card (1/4..4/4 players),
Americano/Mexicano live screen, tournament brackets (8/16/32/64) + pools, token wallet with history,
player reliability status (Normal / Sous surveillance / Suspendu / Bloqué).

Spaces: Player (mobile), Club dashboard, Coach space, Admin dashboard (stats, finance, sanctions, settings),
Sponsor space, Public SEO pages (/clubs/tunis, /club/xxx, /coach/xxx, /events, /tournaments).

Phases: 1 MVP (auth, profile, clubs, courts, calendar, booking, payment, club dashboard, simple events);
2 (Open Match, ranking, results, advanced profile); 3 (Americano, Mexicano, tournaments);
4 (coaching, tokens, subscriptions, sponsors, ads); 5 (native-ready components).
